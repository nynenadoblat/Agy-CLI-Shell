# ⚡ Antigravity Agent Launcher (Оболочка для запуска агента)

Удобная настольная графическая оболочка (Desktop GUI) для запуска и управления сессиями автономного ИИ-разработчика **Antigravity CLI** (`agy.exe`).

---

## 🚀 Быстрый запуск (Нативно в Windows)

Не требует установки Python или сторонних пакетов:
1. Просто дважды кликните по файлу **`Start-Launcher.bat`** (или запустите `AntigravityGUI.ps1` через PowerShell).
2. Откроется графическое окно приложения с темной темой.

> [!TIP]
> Для диагностики в случае сбоев используйте **`Start-Launcher-Debug.bat`** — он оставит окно консоли открытым при возникновении ошибок.

---

## 🐍 Вариант на Python (Tkinter)

Если на машине установлен Python 3:
```bash
python antigravity_gui.py
```
Использует только стандартную библиотеку Python (`tkinter`, `subprocess`, `threading`, `json`, `queue`) без необходимости `pip install`.

## ✨ Возможности оболочки

- **Многовкладочный интерфейс (Мульти-сессии диалогов)**:
  - **Одновременная работа с несколькими разговорами**: открывайте сколько угодно независимых диалогов в параллельных вкладках;
  - **Полный параллелизм выполнения**: каждая вкладка имеет собственное изолированное состояние, проект, выбранную модель/режим, независимый FlowDocument и очередь фонового процесса; агент может выполнять сложную задачу в одной вкладке, пока вы параллельно ведёте диалог в другой без малейших взаимных помех;
  - **Живая индикация прогресса**: на заголовке каждой вкладки отображается статусная точка (зелёная — свободен, оранжевая — агент думает/выполняет команды, красная — ошибка) для мониторинга фоновых диалогов;
  - **Удобная навигация и горячие клавиши**:
    - **`➕`** (расположена сразу за крайней правой вкладкой) или **`Ctrl + T`** — открыть новую вкладку с чистым диалогом;
    - **`✖`** на вкладке (увеличенный хитбокс 20x20px с подсветкой при наведении), клик средней кнопкой мыши или **`Ctrl + W`** — гарантированное закрытие вкладки (с корректной остановкой фонового процесса агента, если он работал);
    - **`Ctrl + Tab`** / **`Ctrl + Shift + Tab`** — мгновенное переключение между соседними вкладками;
    - Защита от пустого состояния: при закрытии последней вкладки лаунчер автоматически создаёт новую готовую сессию.
- **Удобный ввод и отправка**:
  - Нажатие **`Enter`** немедленно отправляет сообщение агенту;
  - **`Shift + Enter`** вставляет перенос строки для составления структурированных многострочных запросов.
- **Выбор проекта / Workspace**:
  - Текстовое поле с возможностью ручного ввода или кнопка «Обзор...».
  - Выпадающий список с авто-обнаружением всех ваших проектов внутри каталога `IGROSTROY` (`Voxel Bastion Co-op 2`, `Fleas vs Robots...`, `Test Rig` и др.).
- **Выбор модели**:
  - `gemini-3.8-flash-high` (по умолчанию, максимальная скорость и точность);
  - `gemini-3.8-flash-medium` / `gemini-3.8-flash-low`;
  - `claude-sonnet-4-6` / `claude-opus-4-6-thinking`;
  - `gpt-oss-120b-medium`.
- **Режимы работы агента (`--mode`)**:
  - `auto` — автономное принятие решений и выполнение задач;
  - `plan` — режим планирования без прямого изменения кода;
  - `accept-edits` — режим с подтверждением правок.
- **Уровень рассуждений (`--effort`)**: `high`, `medium`, `low`, `xhigh`, `max`.
- **Авто-подтверждение прав**: флаг `--dangerously-skip-permissions` для безостановочной работы без запросов подтверждения в консоли.
- **Потоковый вывод (Streaming)**:
  - Ответы агента генерируются и отображаются в реальном времени символ за символом через NDJSON протокол `agy.exe --output-format stream-json`.
  - Отображение статуса вызова инструментов (`[Вызов инструмента: ...]`).
- **Управление разговорами и сессиями (История диалогов)**:
  - Выпадающий список **«Разговор»** на верхней панели для быстрого переключения между недавними диалогами;
  - Кнопка **«💬 Все диалоги...»** (или клик по ID в статус-баре) открывает специализированное окно менеджера сессий;
  - **Пользовательские названия разговоров (Переименование диалогов)**:
    - **Двойной клик по заголовку любой вкладки**: мгновенно открывает модальное окно ввода нового названия диалога;
    - **Контекстное меню вкладки (Правый клик)**: пункт `✏️ Переименовать вкладку...` для быстрого редактирования имени;
    - **Кнопка «✏️ Переименовать» в окне «Все диалоги...»**: переименование любого сохранённого разговора прямо в таблице менеджера сессий;
    - **Мгновенная синхронизация и сохранение**: новое название сразу же обновляется в заголовке вкладки, в выпадающем списке ComboBox и сохраняется в локальном кэше `sessions_meta.json`;
    - Заданные имена сохраняются между перезапусками лаунчера и имеют наивысший приоритет над автоматически извлечёнными первыми строками запросов;
  - **Мгновенный поиск** по тексту запроса, проекту, дате или GUID диалога;
  - **Таблица сессий** с датой, проектом, количеством ходов и темой диалога;
  - **Панель предпросмотра**: отображает первый запрос и последний ответ агента для выбранной сессии;
  - **Восстановление переписки**: при выборе диалога его история автоматически загружается в окно чата, рабочая папка переключается на проект диалога, а новые запросы продолжают разговор с сохранением полного контекста (`--conversation <id>`);
  - **Плавная асинхронная загрузка с анимированным оверлеем (No-Freeze)**: считывание и JSON-парсинг истории даже для огромных диалогов (5000+ строк) вынесены в фоновый поток без блокировки основного UI; во время загрузки отображается стильная карточка с круговым вращающимся спиннером (`#4FC1FF`), неоновым свечением и строкой состояния, исключая любые затормаживания или зависания интерфейса;
  - **Автоматическая прокрутка вниз**: при загрузке любого диалога из истории (через окно диалогов или выпадающий список) и при переключении вкладок чат гарантированно и мгновенно прокручивается в самый низ (`Scroll-ChatLogToEnd`), открывая последние сообщения и поле ввода без необходимости ручной прокрутки;
  - Запуск выбранного диалога в интерактивной консоли через кнопку **«🖥️ Открыть в TUI»**;
  - **Безопасное удаление диалогов**: кнопка **«🗑️ Удалить»** в окне «Все диалоги» позволяет безвозвратно удалить выбранную сессию с диска (`~/.gemini/antigravity-cli/brain/<id>`) с запросом подтверждения;
  - Кнопка **«➕ Новый диалог»** для быстрого начала сессии с чистого листа.
- **Непрерывный контекст сессии**:
  - Оболочка автоматически сохраняет и кэширует метаданные сессий (`sessions_meta.json`).
- **Поддержка скриншотов и изображений (Мультимодальность)**:
  - **Вставка из буфера обмена (`Ctrl + V`)**: мгновенно прикрепляйте скриншоты экрана (сделанные через `Win + Shift + S` или PrintScreen) простым нажатием `Ctrl + V` в любой части окна или в поле ввода;
  - **Кнопка «📎 Картинка»**: диалог выбора одного или нескольких файлов изображений (`.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.gif`);
  - **Drag & Drop**: просто перетащите файлы картинок из проводника Windows в окно лаунчера;
  - **Интерактивная панель вложений**: наглядные карточки с миниатюрой (Thumbnail), разрешением/размером файла и кнопкой удаления (`✖`);
  - **Умная доставка агенту**: изображения сохраняются в папку вложений проекта (`.antigravity/attachments/`), а агент автоматически получает инструкции и пути для их чтения через инструмент `read_file`.
- **Графическое отслеживание заполненности контекста модели (Context Window Analytics & Tokens Tracking)**:
  - **Интерактивный графический виджет в статус-баре**:
    - **Стилизованный ProgressBar**: аппаратный плоский индикатор с закругленными углами, темным треком (`#14161C`) и плавной цветной полосой заполнения;
    - **Числовой счетчик**: компактное отображение использованного объема токенов и лимита модели (например: `107.9k / 1.0M`);
    - **Цветной бейдж-пилюля с процентом**: наглядный акцентный блок (например: `[10.3%]`), динамически меняющий фоновую подсветку и контур;
  - **Трехуровневая цветовая сигнализация**:
    - Мятно-зеленый (`#4EC9B0`) — оптимальная нагрузка (< 60%), свободный контекст;
    - Янтарно-оранжевый (`#E2C08D`) — предупреждение о заполнении (60% – 80%);
    - Кораллово-красный (`#F85149`) — критическая заполненность (> 80%), явный сигнал о необходимости оптимизации или выполнения команды `/compact`;
  - **Модальное окно глубокого анализа («🧠 Анализ контекстного окна»)**:
    - Открывается по клику левой кнопкой мыши по графическому виджету в статус-баре;
    - Большая графическая полоса прогресса с процентной шкалой (0% ... 50% ... 100%);
    - 4 информационные карточки метрик:
      - ⚡ **КЭШ** (`Cache Read`): токены предыстории диалога, сохраненные и повторно используемые без затрат;
      - 📥 **ВХОД** (`Input Tokens`): новые запросы пользователя и системный промпт;
      - 📤 **ОТВЕТ** (`Output Tokens`): токены последней генерации модели;
      - 🛡️ **ЗАПАС** (`Headroom`): свободный резерв токенов и доступный процент емкости окна;
    - Статусный баннер с экспертными рекомендациями (уведомления об оптимальности, предупреждения или совет выполнить `/compact`);
    - Кнопка **«📋 Скопировать отчет»** для мгновенного сохранения текстовой сводки в буфер обмена;
  - **Псевдографическая шкала (Unicode Bar)**:
    - В окне «Все диалоги...» панель предпросмотра отображает текстово-графическую полосу вида `[██░░░░░░░░░░░░░░░░░░] 10.3% (107.9k / 1.0M)` с разбивкой на входные данные, кэш и генерацию;
  - **Автоматический учет лимитов каждой модели**:
    - `gemini-3.8-flash-*` — лимит **1 000 000 токенов (1M)**;
    - `gemini-1.5-pro` / `gemini-2.0-pro` / `gemini-2.5-pro` — лимит **2 097 152 токенов (2M)**;
    - `claude-sonnet-4-6` / `claude-opus-4-6-thinking` — лимит **200 000 токенов (200k)**;
    - `gpt-oss-120b-medium` — лимит **128 000 токенов (128k)**;
  - **Изоляция по вкладкам**: при переключении между вкладками статус-бар моментально переключается на счетчик контекста выбранного диалога;
  - **Глубокая всплывающая подсказка (ToolTip)** при наведении мыши с подробной детализацией.
- **Масштабирование шрифта (Zoom)**:
  - Зажмите **`Ctrl` + колесико мыши** для плавного изменения размера текста (от 8pt до 36pt);
  - Горячие клавиши: **`Ctrl +`** / **`Ctrl -`** для приближения и отдаления;
  - Сброс масштаба к 100%: нажмите **`Ctrl 0`** или кликните по индикатору масштаба (`🔍 100%`) в статус-баре;
  - **Автосохранение**: выбранный размер шрифта, геометрия и размеры окна (ширина, высота, состояние полноэкранного режима) автоматически сохраняются в `launcher_config.json` и восстанавливаются при последующих запусках лаунчера.
- **Остановка и отмена**: кнопка **«⏹ Стоп»** мгновенно прерывает зависший или слишком долгий процесс агента.
- **Интерактивный терминал**: кнопка **«🖥️ Открыть TUI»** открывает полноценный терминальный интерфейс `agy` в отдельном окне.
- **Сворачиваемые интерактивные блоки вызовов инструментов (Collapsible Cards)**:
  - Автоматическая группировка последовательных системных операций (`read_file`, `run_command`, `edit_file` и др.) в аккуратную однострочную карточку;
  - В процессе выполнения отображает активный инструмент (`⚙️ Выполняется: run_command...`) и текущее время;
  - При начале ответа агента карточка автоматически сворачивается в компактную плашку: `⚙️ Вызовы инструментов (7 операций) • 3.98 сек  ▶ Развернуть (7)`;
  - Интерактивное раскрытие/сворачивание: клик по шапке карточки мгновенно раскрывает подробный список каждого инструмента с длительностью выполнения и статусом;
  - Поддержка сворачивания как при живом потоковом общении, так и при открытии прошлых диалогов из истории транскриптов.
- **Интерактивные сворачиваемые карточки системных уведомлений (`<SYSTEM_MESSAGE>`)**:
  - Автоматическое распознавание и перехват системных сообщений, служебных событий (`<SYSTEM_MESSAGE>...</SYSTEM_MESSAGE>`), уведомлений об остановке фоновых задач и статусов выполнения (`Task id "..." finished with result`);
  - **Полная фильтрация сырой разметки**: теги `<SYSTEM_MESSAGE>`, `</SYSTEM_MESSAGE>`, `<ADDITIONAL_METADATA>` и системные преамбулы больше никогда не засоряют текст запросов пользователя или лог чата;
  - **Эстетичный темный стиль карточки**: благородный темно-серый фон (`#1F2428`), мягкая синяя рамка акцента (`#388BFD`), выразительный заголовок с иконкой колокольчика (`🔔 Системное уведомление: <суть>`);
  - **Умное сокращение идентификаторов задач**: длинные 36-значные GUID в заголовках задач автоматически сокращаются (например, `Task id "task-288" finished with result: ExitCode 0`), делая плашку информативной и компактной;
  - **Свернуто по умолчанию (Start Collapsed)**: системные сообщения не загромождают диалог и не отвлекают от сути обсуждения;
  - **Интерактивное раскрытие в один клик**: клик по шапке карточки или кнопке `▶ Развернуть` / `▼ Свернуть` открывает полный подробный текст сообщения в моноширинном контейнере (`Consolas`, `#161B22`) без сдвигов и прыжков скролла;
  - Поддержка как при живом стриминге событий, так и при открытии истории переписки из транскриптов.
- **Полноценный рендеринг Markdown (Жирный текст, курсив, инлайн-код, блоки кода с подсветкой)**:
  - **Инлайн-стили**:
    - `**жирный**` или `__жирный__` — яркий белый акцент с полужирным начертанием (`FontWeight="Bold"`);
    - `*курсив*` или `_курсив_` — наклонный шрифт (`FontStyle="Italic"`);
    - `***жирный курсив***` — комбинация обоих стилей;
    - `` `инлайн код` `` — моноширинный шрифт `Consolas`, тёмная подложка (`#28282B`) и терракотовый цвет синтаксиса (`#CE9178`);
    - `~~зачеркнутый~~` — аккуратная горизонтальная зачёркивающая линия;
    - `[ссылка](url)` — кликабельная интерактивная гиперссылка с открытием в браузере.
  - **Блоки кода (` ```lang ... ``` `)**:
    - Автономный тёмный контейнер (`#161618`) с тонкой рамкой (`#2D2D30`) и скруглёнными углами;
    - Верхняя шапка с указанием языка программирования (`csharp`, `powershell`, `json`, `python` и др.);
    - Интерактивная кнопка **`📋 Копировать`** в один клик копирует весь блок кода в буфер обмена Windows с индикацией `✔ Скопировано!`;
    - Моноширинное выделяемое поле с удобной прокруткой и переносом строк без потери табуляций и отступов.
  - **Структурные элементы текста**:
    - **Заголовки (`# H1`, `## H2`, `### H3`, `#### H4`)**: многоуровневая иерархия с увеличенным кеглем и фирменными цветами VS Code (`#4FC1FF`, `#4EC9B0`, `#E2C08D`, `#DCDCAA`);
    - **Маркированные списки (`- `, `* `)**: аккуратные отступы с цветными маркерами `•` и `○`;
    - **Нумерованные списки (`1. `, `2. `)**: автоматическое форматирование шагов алгоритмов и планов;
    - **Цитаты (`> `)**: вертикальная акцентная синяя полоса слева (`#007ACC`) и контрастный фон блока;
    - **Таблицы (`| колонка | ... |`)**: структурированные адаптивные таблицы с полужирной подсветкой заголовков (`#4EC9B0`), тонкими рамками ячеек и чередующимся фоном строк;
    - **Разделительные линии (`---`, `***`)**: тонкая эстетичная черта для разграничения смысловых разделов.
  - **Умная динамическая трансформация (Smart Live Streaming)**:
    - Во время генерации ответа токены выводятся плавно и мгновенно без малейших задержек или мерцания;
    - В момент завершения генерации (или перед выполнением команды) сырой текст моментально трансформируется в безупречно отформатированный Markdown;
    - При открытии любого сохранённого диалога из истории транскриптов вся переписка сразу же отображается в полноценной Markdown-разметке.
- **Цветовая подсветка типов текста и синтаксиса в чате**:
  - Насыщенное форматирование на базе `RichTextBox` (FlowDocument) с аппаратным кэшированием замороженных кистей (`SolidColorBrush.Freeze()`) для нулевого влияния на производительность стриминга;
  - 🔷 **Сообщения пользователя**: жирный бирюзовый заголовок `[Вы (HH:mm:ss)]:` (`#4FC1FF`) и контрастный белый текст запроса (`#F1F1F1`);
